# Thumb-2 指令与寻址

面向 STM32H743、Cortex-M7 和 GNU Arm 工具链。阅读 CubeIDE 反汇编时，先区分寄存器编号、地址数值和地址里的数据。同一段 C 代码在不同优化等级下可能生成不同指令。

## 从 MOV、LDR 和 STR 开始 {#load-store}

### `LDR R0, [R1]` 的精确语义

假设：

```text
CPU 中：
  R1 = 0x20000000
  R0 = 0

DTCM RAM 中：
  地址 0x20000000 保存着 32 位整数 100
```

执行：

```asm
LDR R0, [R1]
```

结果：

```text
R0 = 100
R1 = 0x20000000（不变）
RAM[0x20000000] = 100（不变）
```

- **`R0`**：读取结果的目的寄存器。
- **`R1`**：保存目标内存地址。
- **`[R1]`**：访问 R1 中的地址所指向的内存，而**不是**读取 R1 本身。

对比：

```asm
MOV R0, R1         @ R0 = R1，复制地址数值本身
LDR R0, [R1]       @ R0 = RAM[R1]，读取内存内容
STR R0, [R1]       @ RAM[R1] = R0，写入内存内容
LDR R0, [R1, #4]   @ R0 = RAM[R1+4]，地址偏移 4 字节
```

若 R1 = `0x20000000`，最后一条访问的是 `0x20000004`，不是“第 4 个 `uint32_t` 元素”。

### 常见符号对照

| 符号 | 例子 | 作用 |
| --- | --- | --- |
| `[]` | `[R1]` | 表示内存寻址；也可包含基址与偏移量 |
| `{}` | `{R4, R5, LR}` | 表示寄存器**列表**，常见于 `PUSH` / `POP` |
| `#` | `#10` | 立即数，表示字面整数 10 |
| `!` | `[R1, #4]!` | 地址写回：执行寻址时更新基址寄存器 |
| `=` | `LDR R0, =0x12345678` | 汇编器加载常数的伪指令语法 |
| `,` | `ADD R0, R1, R2` | 分隔操作数 |

> 注意：汇编的 `{R4, R5}` **不是** C 语言的代码块花括号，而是“寄存器集合”；`[R1]` 也不能简单理解成 C 数组下标，它表示按地址访问内存。

## 常见指令速查

STM32H743 的 Cortex-M7 执行 Thumb 指令集，指令编码可以是 16 位或 32 位。指令编码的宽度和访存数据的宽度分别由指令形式决定。

### 数据读写与栈

| 指令 | 典型示例 | 含义 |
| --- | --- | --- |
| `MOV` | `MOV R0, R1` | 把 R1 的值复制到 R0，不访问普通内存 |
| `LDR` | `LDR R0, [R1]` | 从 R1 指向的地址读取 32 位数据，存入 R0 |
| `STR` | `STR R0, [R1]` | 把 R0 的 32 位值写入 R1 指向的地址 |
| `LDRB` / `STRB` | `LDRB R0, [R1]` | 读取 / 写入 8 位数据 |
| `LDRH` / `STRH` | `LDRH R0, [R1]` | 读取 / 写入 16 位数据 |
| `PUSH` | `PUSH {R4, LR}` | 将一组寄存器的值保存到当前栈 |
| `POP` | `POP {R4, PC}` | 从当前栈恢复一组寄存器，写入 PC 可返回 / 跳转 |

### 算术与位操作

| 指令 | 典型含义 | C 语言近似表达 |
| --- | --- | --- |
| `ADD` / `SUB` | 加法 / 减法 | `a + b` / `a - b` |
| `MUL` | 整数乘法 | `a * b` |
| `SDIV` / `UDIV` | 有符号 / 无符号整数除法 | `a / b` |
| `AND` / `ORR` / `EOR` | 按位与 / 或 / 异或 | `&` / `\|` / `^` |
| `BIC` | 按掩码清零位 | `a & ~mask` |
| `LSL` / `LSR` / `ASR` | 左移 / 逻辑右移 / 算术右移 | `<<`，以及不同语义的右移 |
| `UXTB` / `SXTB` | 提取低 8 位并零扩展 / 符号扩展 | 协议字节、带符号数据处理 |
| `REV` | 反转 32 位数的字节顺序 | 大小端转换 |

### 比较、跳转与特殊指令

| 指令 | 作用 |
| --- | --- |
| `CMP` | 比较操作数，更新条件标志（不保存减法结果） |
| `TST` | 按位与测试，更新条件标志 |
| `B` | 无条件跳转 |
| `BEQ` / `BNE` | Z 标志指示相等 / 不相等时跳转 |
| `BGT` / `BLT` | 有符号大于 / 小于时跳转 |
| `CBZ` / `CBNZ` | 寄存器为零 / 非零时跳转 |
| `BL` | 跳转调用函数，并更新 LR（返回位置） |
| `BX LR` | 按 LR 的值进行分支，常用于普通函数返回 |
| `MRS` / `MSR` | 读 / 写特殊寄存器，如 PRIMASK、CONTROL |
| `CPSID i` / `CPSIE i` | 禁止 / 允许可配置优先级中断；并非屏蔽所有异常 |
| `DMB` / `DSB` / `ISB` | 内存顺序 / 同步 / 指令流屏障 |
| `WFI` / `NOP` | 等待中断 / 空操作 |
| `LDREX` / `STREX` | 独占访存，常用于同步原语 |

> **易错点**：`MOV` 是寄存器传值；`LDR` 是读取内存；`STR` 是写入内存。`LDR R0, =0x12345678` 中的 `=` 属于汇编器的加载常量伪指令形式，不保证一定对应一条物理机器指令。

## 从反汇编追踪读写地址 {#disassembly}

在 CubeIDE 的 Disassembly 和 Registers 窗口对照单步，记录两条 `LDR` 取出的值以及最终写入地址。

```asm
bl   HAL_GPIO_TogglePin
ldr  r3, [pc, #24]
ldr  r3, [r3, #0]
adds r3, #1
str  r3, [r2, #0]
```

| 指令 | 真实操作 |
| --- | --- |
| `BL HAL_GPIO_TogglePin` | 跳转调用，LR 记录返回位置 |
| `LDR R3, [PC, #24]` | 从 PC 相对地址位置读取一个 32 位字（常见于常量池） |
| `LDR R3, [R3, #0]` | 将刚取出的值作为内存地址，读取该地址的数据 |
| `ADDS R3, #1` | 把 R3 加 1，并更新相关条件标志 |
| `STR R3, [R2, #0]` | 将 R3 写到 **R2 指向的地址**，不是自动写回刚才 R3 读过的地址 |

仅凭这五条指令，**不能断言**最后一定写回某个指定的全局变量：还需要查看 R2 当时保存的地址，以及前后的指令、反汇编地址和符号表。
